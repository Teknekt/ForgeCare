# ForgeCare v1.1 Beta Issue Reporting

The initial `v1.1.0-beta.1` target is an unsigned Windows 11 x64 controlled beta.

For each `v1.1.0-beta.1` issue, record:

- ForgeCare version and artifact filename;
- Windows edition, version, and build;
- installed or portable mode;
- normal-user or administrator context;
- active workflow stage;
- action attempted;
- expected and observed behavior;
- reproducibility and minimal safe reproduction steps;
- Regression Suite PASS/WARN/FAIL summary;
- whether a Debug Bundle exists and whether it was reviewed before sharing.

If the application remains usable, export a Debug Bundle from **Tools** only after reviewing `V1.1_BETA_PRIVACY_SUPPORT.md`.

Do not paste or attach passwords, API keys, bearer tokens, private keys, raw customer data, unrelated personal files, or unreviewed support bundles. Do not weaken Windows security controls to reproduce a problem.
