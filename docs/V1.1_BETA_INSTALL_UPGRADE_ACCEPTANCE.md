# ForgeCare v1.1 Beta Phase D Install and Upgrade Acceptance

Status: **PENDING PHASE D MANUAL ACCEPTANCE**. These steps are procedures, not completed results.

The target is an unsigned ForgeCare `v1.1.0-beta.1` beta for Windows 11 x64.

## Artifact integrity

Verify `ForgeCare-v1.1.0-beta.1-win-x64-portable.zip` and `ForgeCare-v1.1.0-beta.1-Setup.exe` against the SHA-256 values and source commit in the generated release metadata. Confirm `signed: false` and the Windows 11 x64 target.

## Fresh installer

On a non-critical Windows 11 x64 test user: install per-user, launch without developer tooling, confirm the beta version, run preflight and a read-only session, close, and confirm normal restart.

## Portable

Extract to a user-writable folder, launch without installer/developer tooling, confirm beta identity and LocalAppData persistence, then complete the read-only baseline flow.

## v1.0 to v1.1 beta upgrade

Using an authentic v1.0 installation and existing data, record settings, session, Evidence, Safety/recovery, and report-history state. Install the beta with the unchanged AppId. Confirm upgrade-in-place and verify every recorded data category remains readable. Do not fabricate or migrate data merely to pass.

## Uninstall and reinstall

Create representative ForgeCare data, uninstall, verify installer-owned binaries are removed and intended LocalAppData remains, reinstall, then confirm preserved settings/session/Evidence/Safety/report history load normally.

Record exact PASS/WARN/FAIL results, artifact hashes, Windows build, installation mode, and any SmartScreen prompt. Stop on data loss, unsafe behavior, or an unexplained compatibility failure.
