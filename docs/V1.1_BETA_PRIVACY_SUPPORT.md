# ForgeCare v1.1 Beta Privacy and Support Artifacts

ForgeCare `v1.1.0-beta.1` is local-first. Sprint 27 introduces no telemetry and ForgeCare does not automatically upload reports, logs, Evidence, recovery data, or Debug Bundles.

The initial Windows 11 x64 beta is unsigned; review SmartScreen prompts and verify artifact hashes rather than disabling Windows protections.

## Professional Service Report

The Professional Report is the privacy-bounded technician/customer handoff artifact. It summarizes recorded diagnostics, actions, verification, checkpoints, unresolved items, and compact Evidence references. It intentionally excludes raw Evidence observation bodies and recovery identifiers.

## Debug Bundle

The Debug Bundle is an engineering support artifact, not a customer report. It can include:

- privacy-minimized environment and crash diagnostics;
- ForgeCare settings;
- reports/session support state;
- persisted Evidence;
- Safety journal and recovery snapshots.

Historical local crash history is projected into a privacy-safe crash diagnostic before bundle inclusion. The raw local `crash.log` is not copied into the shareable Debug Bundle, and the local history is not rewritten or deleted. The projection retains bounded timestamps, contexts, versions, and exception types while omitting legacy machine/user identity, raw messages, paths, and stack traces.

The Beta Issue Package uses the same privacy-safe crash projection. Raw historical `crash.log` content is not copied into either shareable support ZIP. Technician-entered issue descriptions, reproduction steps, expected results, and actual results remain intentional support context and may contain information supplied by the technician.

Copy warnings contain bounded category/status/failure-type information rather than raw local paths or exception messages. Other copied source documents may still contain local diagnostic or recovery information. Open and review every Debug Bundle or Issue Package ZIP before sharing it. ForgeCare does not upload these packages automatically.

## Startup recovery and undo

Supported Startup recovery may need to retain original local configuration values so ForgeCare can restore them. This state remains local unless the technician deliberately shares files containing it. Privacy hardening must not remove information required for recovery.

Never send passwords, tokens, API keys, private keys, unrelated personal documents, or raw customer data with a support request.
