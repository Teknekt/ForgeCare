\## Known limitations



\### Windows SmartScreen



The v1.0.0 binaries are not code-signed.



Microsoft Defender SmartScreen may therefore identify the installer as

coming from an unknown publisher and display a warning before execution.



SHA-256 fingerprints are provided with the official release for

artifact verification.



Code signing is planned for a future release.



\### Remote updates



Remote update discovery infrastructure is not yet configured for

automatic public update delivery.



The v1.0.0 release manifest supports the foundation of future update

discovery, but installer download and execution remain intentionally

disabled.



\## Release policy



v1.0.0 is now considered frozen.



Development after this release takes place outside the v1.0.0 release

commit/tag.



Critical defects may result in a v1.0.1 maintenance release.



New functionality belongs to the v1.1 development line.
