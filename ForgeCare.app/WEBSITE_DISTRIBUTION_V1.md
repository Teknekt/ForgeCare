# ForgeCare Website Distribution — v1

Normal public download:

`ForgeCare-v1.0.0-Setup.exe`

That single self-contained installer is the recommended website download.

Optional advanced download:

`ForgeCare-v1.0.0-win-x64-portable.zip`

Recommended website presentation:

**ForgeCare Technician Edition**
- Download for Windows
- Installer — Recommended
- Portable — Advanced / technicians

The installer contains the published self-contained ForgeCare application, so the end user does not need the source project or Visual Studio/.NET SDK.

For a polished public release, code signing remains strongly recommended to reduce Windows SmartScreen friction and establish publisher identity.
