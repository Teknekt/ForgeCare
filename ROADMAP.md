# ForgeCare Public Roadmap

ForgeCare development is guided by technician usefulness, safety and validated real-world feedback rather than feature count.

## Current — v1.0.0

The first public Technician Edition release establishes the core workflow:

**Scan → Analyze → Plan → Forge → Verify → Report**

## Next — v1.1

Priorities will be refined from real-world use. Current focus areas are:

- fix reproducible issues found on external Windows machines
- improve first-run and installation clarity
- strengthen diagnostics accuracy and performance
- improve review/confirmation UX for technician actions
- improve verification and before/current comparisons
- improve professional report quality
- clarify recovery, safety and troubleshooting paths

## Later

Potential capabilities are evaluated only when they improve technician workflows without weakening review and safety principles.

This roadmap is directional, not a promise of dates or specific features. Public issues and technician feedback are used to validate priorities.
